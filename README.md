# djangopal

## Make virtual environment
```sh
python -m venv venv
```

## Activate virtual environment
```sh
source venv/bin/activate # macOS/Linux
venv\Scripts\activate # Windows
```

## Install Django
```sh
pip install django
```

## How the app was created
```sh
django-admin startproject hello .
```

## How to run the app
```sh
python manage.py runserver
```
